# 凤凰知音里程计算

一个只使用凤凰知音官方 `mileageCumulateCalculation` 接口的多航段里程计算器。

## 本地运行

```bash
python3 server.py
```

访问 <http://127.0.0.1:8766/index.html>。

## 计算口径

- 用户填写实际承运航司两字码（保留 CA / ZH / NX / SC / KY 等常用快捷提示）、日期、航班号、起止机场三字码和订座舱位；外航规则由凤凰知音官方接口返回。
- 航班号数字可留空；留空时工具向官方接口提交对应航司的 `0` 通用规则参数，以减少不必要输入，但该结果不代表真实航班存在。
- 起止机场联想读取国航官网机场代码资源并合并少量新航点补充数据，支持中文、拼音、首字母和 IATA 搜索，以及方向键和回车选择。联想数据不作为白名单，任何格式正确的 IATA 三字码都可直接提交；当前补充 ZAG（萨格勒布）。
- 会员卡等支持普通卡、儿童卡、银卡、金卡、白金卡和终身白金卡，使用官方参数独立查询。
- 服务端将每个航段原样提交给凤凰知音官方累计接口。
- 可用里程、定级里程、舱位比例均直接取官方响应；前端只求和及计算“每 1 元获得里程”。
- 查询结果按官方返回顺序展示每个航段的完整累计档位表，并标出当前选择的舱位档。
- 舱位由用户手工输入一个订座舱位字母，并由官方累计接口校验和计算。
- 官方累计接口不负责核验航班号是否与所填航线真实匹配。

## 航班号可选的实验依据

对国内 PEK–SHA 和国际 PEK–ARN、CGK–PEK、PEK–SIN 等航线进行对照后，所选航司代码加 `0` 会返回按起止机场、日期、航司与卡等计算的官方通用档位；在四组可比查询中与真实航班号返回完全一致。任意伪造航班号则不可靠：可能被拒绝，也可能返回零累计或错误兜底规则。因此工具只在用户留空时使用明确的 `航司代码 + 0`，不会自动编造其他航班号。日期仍保留，因为空日期会被官方接口拒绝，跨时期也可能命中不同规则。
